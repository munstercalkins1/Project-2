# Project 2 — NIKE FCFF Decision Package

## Run the model

```powershell
python nike_fcff_application.py
```

This command regenerates `nike_fcff_output.md`, the visible five-year FCFF
valuation output. The committee decision is in `COMMITTEE_MEMO.md`; validation,
the changed-input record, and cold-run evidence are in `VALIDATION_RECORD.md`.

## Folder map

- `nike_fcff_application.py` — linked five-year FCFF model and validations.
- `nike_fcff_output.md` — readable baseline output and decision numbers.
- `COMMITTEE_MEMO.md` — conditional committee recommendation.
- `VALIDATION_RECORD.md` — baseline, mandate, changed-input, and cold-run records.
- `ASSUMPTION_REGISTER.md` and `SOURCE_MAP.md` — forecast judgments and filing evidence.
- `nike_*`, `lab08_nike_pe.md`, `lab10_nike_proforma.md`, `lab11_nike_sensitivity.md`, and `PEER_MULTIPLES.md` — supporting analysis and cross-checks.
- `VIDEO_SCRIPTS_FINAL.md` — recording scripts; add final working video/transcript links before submission.

This folder is a copied submission package. The original course files remain at
the repository root.
